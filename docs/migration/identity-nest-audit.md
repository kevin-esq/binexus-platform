## Hallazgos críticos para el diseño .NET

1. **Refresh Nest = JWT**; requisito Gate Identity pide **opaque RNG** — cambio intencional de representación interna; contrato HTTP `{ refreshToken: string }` se mantiene.
2. **Sin reuse/family** en Nest — se añade (requisito explícito).
3. **Sin tests Nest** de auth — cobertura nueva completa en .NET.
4. **Argon2id** PHC: `$argon2id$v=19$m=65536,t=3,p=4$...` — obligatorio verificar desde .NET.
5. **SDK** carece de `refresh()`; `logout()` no manda body — corregir en generación/SDK.
6. **tenant_features** en seed Nest — **no** migrar en Identity salvo decisión Platform; Identity seed solo tenants/branches/users (+ refresh vacío).
