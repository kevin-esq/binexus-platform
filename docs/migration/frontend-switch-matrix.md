# Gate 5 — Frontend → .NET compatibility matrix

Date: 2026-07-12  
Scope: operator panel `apps/web` against Nest (`apps/backend` :3001) vs .NET (`Binexus.Api` :5102), via `@binexus/sdk`.  
Sources: `packages/sdk/src/client.ts`, `artifacts/openapi/binexus-v1.json`, Nest controllers under `apps/backend/src/contexts/**`, module checkpoints in `docs/migration/`.

**Estado legend**

| Estado        | Meaning                                                               |
| ------------- | --------------------------------------------------------------------- |
| OK            | Path + body shape work as used by the UI today                        |
| GAP           | Works for happy path; missing hardening or parity the UI should gain  |
| NEEDS_ADAPTER | UI/SDK must change before .NET feels correct (errors, headers, env)   |
| BLOCKED       | Feature cannot complete against seeded .NET without ops/config change |

Base URL today: `apps/web/src/lib/api.ts` → `NEXT_PUBLIC_API_URL ?? http://localhost:5102` (.NET Gate 5 default).  
Nest comparison: set `NEXT_PUBLIC_API_URL=http://localhost:3001`.  
.NET launch profile: `http://localhost:5102` (`backend/src/Binexus.Api/Properties/launchSettings.json`). Nest: `BACKEND_PORT ?? 3001`.

Checkpoint: [`frontend-switch-checkpoint.md`](./frontend-switch-checkpoint.md).

## KEEP_EXACT mismatches (HTTP contract vs reality)

From [`BASELINE.md`](./BASELINE.md) §3.2 vs this audit:

1. **Approve order** — classified BEHAVIOR_CHANGE (sync stock). Not KEEP_EXACT for success/failure semantics.
2. **Error envelope** — Nest filter ≠ Problem Details. Public codes mostly stable; field names are not.
3. **ID format** — cuid → UUIDv7 breaks path binding and cursors across backends.
4. **Create order status** — .NET returns `201` with `Location` on first create; Nest historically `{id}` (SDK ok).
5. **OpenAPI** — `ProblemDetails` schema omits `code`; approve/cancel/requeue `200` schemas empty; `OpenSalesSessionRequest.branchId` marked required in OpenAPI though runtime allows JWT fallback (`Guid?`).
6. **AuthBranch** — .NET drops `tenantId` vs `@binexus/types` `Branch`.
7. **Idempotency-Key** — documented client concern; SDK + web never send it (Nest optional, .NET auto-generates).

## Prioritized fix list (no Nest deletion)

### P0 — unblock operator panel on .NET

1. ~~**Env:** default `NEXT_PUBLIC_API_URL` / fallback to `:5102`.~~ Done.
2. ~~**SDK error adapter:** Problem Details + Nest `message`.~~ Done.
3. ~~**Enable demo features:** Development seed enables `POS_RETAIL` + `LIQUIDATION`.~~ Done.
4. **Seed data for UI demos:** stock SKUs / branch on JWT user so create-order and POS cart work after feature enable (still ops/data).

### P1 — parity / KEEP_EXACT hardening

5. ~~**Idempotency-Key in SDK:** auto-`crypto.randomUUID()` on mutating methods.~~ Done.
6. **Approve UX:** surface `INSUFFICIENT_STOCK` distinctly on `/orders/[id]` (error text now works; dedicated copy optional).
7. **OpenAPI/SDK regen:** document `code` on ProblemDetails; fill approve/cancel/requeue response schemas; mark `branchId` optional on open session / create order where JWT supplies it.
8. **AuthSession.branch:** either add `tenantId` to .NET `AuthBranch` or narrow TS type to match wire (avoid false KEEP_EXACT).

### P2 — storage / ops

9. ~~**Logistics storage:** Local Presign → API `/internal/dev-object-storage`.~~ Done. MinIO: configure endpoint + bucket CORS for `localhost:3000`.
10. **Liquidation UI:** when discrepancy, UI only hints “use API”; optional follow-up to collect `lines[]` + reason in the panel.
11. **CORS config:** ensure `Cors:AllowedOrigins` includes the web origin when not using defaults.

### Explicit non-goals for Gate 5 switch

- Do not remove Nest; flip URL only.
- Do not migrate Nest cuid rows into .NET UUID tables in this gate.
- Do not add a public `/features` HTTP API unless product wants UI gating before 403.
